# 快速预览 B 方案接手记录

## 集成位置

工作树 `build/quicklook_wt`，分支 `codex/quicklook-b`。以增强包在线版 `4599513` 为基础，合入 Claude 已完成的四个审查提交及后续审查修复；原工作树保留。

## 本轮行为

- 设置导航改为“快速预览”，内部 `packs` 路由保持兼容。
- 通用页不再重复列出格式与系统扩展。快速预览页依次显示格式总览、系统扩展、增强包管理。
- 按 HTML 恢复格式卡标题、统计、图例和默认展开箭头；宽窗口左侧放分类及说明，右侧放标签，内置与增强格式分行；窄窗口改为上下排列。说明采用实际字体换行测量并复用文本布局缓存，深色增强标签提高对比度。
- 保留媒体、现代图像、RAW 和压缩包四个在线增强包及已有 FFmpeg 来源选择。
- 格式列表读取实际支持表。数量自动去重统计；不采用 HTML 中的示意数量、体积和未经实现支持的后缀。
- HEIC/HEIF 只有检测到 HEIF 与 HEVC 组合，或启用图像包后，才确认可用。AVIF 可以使用系统 AV1 支持或图像包。已停用增强包、无效自定义 FFmpeg 不显示为已启用。
- RAW 与压缩包的系统兼容性仍因设备和系统组件而异；虚线说明“增强支持未启用”，不表示系统绝对不能预览。
- 系统扩展返回页面时异步刷新，不在界面线程上探测解码器。
- 输入框三模式统一 DirectWrite 呈现、命中和选区，使用共享渲染参数；保留原生失败回退，列表自动模式保持原有策略。
- 输入布局最多缓存四条，每条最多 4096 个 UTF-16 字符。文字、字号、字体代际、高度等参数变化时重新布局，光标闪烁可复用现有布局。

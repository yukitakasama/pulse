### 快速预览与增强包

- 设置新增统一的「快速预览」页面，集中展示支持格式、系统扩展及四种预览增强包。
- 格式按内置、增强包、增强包或系统扩展区分；分类说明与格式标签分栏，支持展开收起和窄窗口布局。
- 媒体、现代图像、RAW 相机照片、压缩包增强包与本版一同发布，可在设置中下载；媒体增强也支持使用已有 FFmpeg。
- 改进音视频属性读取和 GIF 缩略图缓存，减少重复处理。

### 输入与打开对话框

- 完善打开对话框的文件操作、侧边栏、地址栏和文件名输入体验。
- 输入框统一文字呈现、选区和命中，保留故障回退；有界布局缓存减少重复计算。
- 修复繁体中文设置搜索和说明文字换行裁切。

### 稳定性

- 修复托盘与会话数据校验、文件操作后引用同步、损坏配置覆盖及保存搜索路径问题。
- 改进搜索条件移交、NOT 条件、跨来源排序和网络搜索取消隔离。
- 修复菜单目标身份、隐藏窗格复用、复制此电脑标签和固定标签入组问题。

### 增强包下载

请在「设置 → 快速预览」中安装增强包；无需手动处理发布附件中的 `.lzms` 文件和增强包 JSON 清单。四个增强包沿用已验证的 1.0.1 内容，本版更新其正式下载位置。
